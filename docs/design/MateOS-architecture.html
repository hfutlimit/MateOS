全局不变量detailed/00 · 8 条
  1. DB 是事实源；Redis 只放 presence / pub-sub / slot 信号量，不持久化
  2. WS reconnect ≠ new attempt，attempt 才是 logical 重试单位
  3. envelope.id 全局去重，terminal 消息 exactly-once
  4. CAS 状态转换：终态变更 WHERE status IN (PENDING,RUNNING)
  5. ProviderKey = string + Registry，零硬编码
  6. Connection 复用 Org/Owner 级，多 Project 共享
  7. Guard 不静默放行：REQUIRE_APPROVAL 视为 403，业务层显式 policy.evaluate()
  8. Slot 提前 reservation：Resolver 选中即 tryAcquireSlot，不等 ACCEPT
