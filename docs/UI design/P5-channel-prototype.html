本页承载的 5 个关键设计决策

  1. 四栏常驻：右栏「成员 + 记忆 + 待办」是产品差异化，不能像 Slack 那样折叠掉。
  2. 消息分 5 形态：人类消息 / Agent 决策卡片 / Agent 输出 / 系统事件 / 记忆申请。MVP 不动手，Agent 的全部价值都在卡片上。
  3. Agent 回复走线程：避免多人多 Agent 平铺刷屏。
  4. 状态点贯穿全局：成员列表、@ 下拉、消息头像、右栏共用一套语义色。
  5. @all 带成本预警：防止误触一次烧掉大量 token。
