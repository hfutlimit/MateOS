Channel × Topic关联上下文版

回应反馈：Topic 不该是一座座孤岛。同一个频道的多个 Topic 相互关联，Agent 决策吃的是整个频道的上下文场。本版用四条机制把"关联"显性化：
  1. 左栏按主线分组。Topic 不再是扁平列表，而是归入「支付回调可靠性 / 退款与一致性」等主线，组内用连接线串起来；选中当前 Topic 时，相关 Topic 高亮为虚线、无关的淡出。
  2. 共享上下文带（主角）。线程顶部展开该 Topic 的可见边界：关联 Topic（含依赖/相关/衍生关系与状态）+ 引用记忆 + 关联 WorkUnit + 上游结论。明确"Agent 在此决策时能看到什么"。
  3. 跨 Topic 溯源。决策卡里出现「↗ 引自另一 Topic 的结论」，并演示跨 Topic 检索把上下文完整度 35%→62% 拉起来——解释 Agent 为何从"缺上下文"转为"可判断"。
  4. 频道关系图。右栏以网络（而非孤立点）呈现频道内 Topic 的连线，当前 Topic 高亮。
